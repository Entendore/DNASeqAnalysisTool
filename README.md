# DNA Sequence Analysis Tool

## Features

- Supports input formats: FASTA, GenBank, raw text, CSV (with sequence column), and NCBI accession fetch.
- Multi-sequence processing.
- Base frequency and GC content calculation.
- ORF detection with customizable translation tables and minimum ORF length.
- Export CSV reports, ORF sequences in FASTA format.
- Visualizations with interactive Plotly plots.
- Web app interface with Streamlit and parameter controls.
